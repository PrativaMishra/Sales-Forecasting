# 📊 Sales Data Analysis and Forecasting

This repository contains a comprehensive data science project focused on analyzing retail sales performance and predicting future trends. Using Python’s data ecosystem, the project transforms raw sales records into actionable business insights.


## 🚀 Project Overview

The analysis explores historical sales data to identify seasonal patterns and high-value product categories. It includes a complete end-to-end pipeline:

- **Data Preprocessing**  
  Cleaning missing values and formatting time-series data.

- **Exploratory Data Analysis (EDA)**  
  Aggregating sales by month and category to identify growth drivers.

- **Predictive Modeling**  
  Implementing Linear Regression to forecast future sales.


## 📈 Key Insights

- 💰 **Total Revenue:** $2,252,607 analyzed  
- 🏆 **Top Category:** Technology generated the highest revenue  
- 🔮 **Forecast:** Predicted sales for the next month ≈ **$322,755**
